## 🚀 Minha trajetória

Minha trajetória profissional me proporcionou experiências em diferentes áreas, permitindo desenvolver uma visão analítica, capacidade de resolução de problemas e compreensão sobre processos e negócios.

Com o passar do tempo, meu interesse por tecnologia e desenvolvimento de soluções digitais se tornou cada vez mais presente, despertando em mim o desejo de aprofundar meus conhecimentos em programação e desenvolvimento de software.

Atualmente, direciono minha carreira para o **Desenvolvimento Front-End**, estudando e desenvolvendo projetos práticos com HTML, CSS, JavaScript, TypeScript e React. E, iniciando meus conhecimentos em Backend para agregar mais conhecimento a esta nova trajetória. 

Durante essa jornada, venho explorando conceitos importantes como componentização, reutilização de código, responsividade, consumo de APIs REST, organização de projetos e boas práticas de desenvolvimento.

Também tenho interesse em automação de processos e inteligência artificial, utilizando ferramentas como n8n e Google Gemini API para explorar novas possibilidades de integração e criação de soluções.

Acredito que minha experiência profissional anterior, aliada aos conhecimentos técnicos que venho construindo, contribui para uma visão mais ampla do desenvolvimento de software, conectando necessidades reais, tecnologia e experiência do usuário.

Meu objetivo é continuar evoluindo como desenvolvedor, construir aplicações cada vez mais completas e transformar conhecimento em soluções que gerem valor.

> "Transformando curiosidade em conhecimento e ideias em soluções."

## 🚀 Projetos em destaque

Projetos pessoais e práticos que representam minha evolução no desenvolvimento de software.

### 👟 SyntaxWear

E-commerce de calçados desenvolvido com React e TypeScript, explorando componentização, organização de interfaces, responsividade e experiência do usuário.

**Conceitos trabalhados:**
- Desenvolvimento de interfaces reutilizáveis.
- Componentização com React.
- Tipagem com TypeScript.
- Estilização responsiva.
- Experiência de compra e interação com o usuário.

### 🚗 FIPE Check

Aplicação web para consulta de preços médios de veículos, utilizando a API REST da Tabela FIPE.

**Conceitos trabalhados:**
- Consumo de APIs REST.
- Requisições assíncronas com JavaScript.
- Manipulação dinâmica do DOM.
- Encadeamento de consultas de marcas, modelos e anos.
- Tratamento de dados e resultados.

### 🐙 GitHub Profile Viewer

Aplicação web que permite pesquisar usuários do GitHub e visualizar informações de seus perfis e repositórios.

**Conceitos trabalhados:**
- Integração com GitHub API.
- Requisições assíncronas.
- Manipulação do DOM.
- Renderização dinâmica de informações.
- Tratamento de estados de carregamento e erros.

### ✨ Fundo Mágico

Aplicação para criação de backgrounds animados, permitindo personalizar cores e gerar automaticamente o código HTML/CSS correspondente.

**Conceitos trabalhados:**
- Manipulação dinâmica de elementos.
- JavaScript.
- Geração de código HTML e CSS.
- Integração com automações.
- Interação com o usuário.
